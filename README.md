# RazeCRM - Agence de Voyage & Omra

Solution SaaS & CRM tout-en-un pour agences de voyages et pèlerinages (Omra / Hajj), intégrant :
- **CRM & Pipeline de Vente** : Gestion des prospects, devis intelligents IA, suivi des acomptes et factures.
- **Gestion des Départs Omra & Pèlerins** : Attribution des chambres, manifestes de vols, visas et paiements échelonnés.
- **Site Web Vitrine & Espace Client** : Catalogue d'offres Omra, packages touristiques, radar hôtelier vers le Haram, et simulateur de devis interactif.
- **Marketing & Campagnes** : Messagerie WhatsApp automatisée et gestion multicanale.

---

## 🛠️ Stack Technique
- **Frontend CRM** : React, Vite, Tailwind CSS, Lucide Icons, Shadcn UI
- **Site Web** : React, Vite, Tailwind CSS, Framer Motion
- **Backend & Base de données** : NestJS, Supabase (PostgreSQL, Auth, Storage, RLS)
